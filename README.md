# Christian Bessa — Design Portfolio

English portfolio for social posts, carousels and YouTube thumbnails. Six independent studies with original-source / final-design comparisons.

- 3 posts, 1080 × 1350 PNG
- 1 carousel, 5 pages, 1080 × 1350 PNG
- 2 thumbnails, 1280 × 720 PNG
- Responsive static site with full-size artwork, slide navigation, downloads and source credits.

Publish with GitHub Pages from the `main` branch, root folder. No build command or external dependencies are needed.

The Before panels show official source images and research, not earlier client designs. Final artwork was produced with AI assistance and is a creative interpretation; it is not scientific imagery. Source credits and article links appear under each study. No affiliation or endorsement by NASA, NOAA or USGS is implied.

Source facts were checked November 15, 2026. The NOAA mapping figure is explicitly dated April 2026. Original agency imagery retains its source terms; no blanket license is claimed over third-party materials.
