# Christian Bessa — Design Portfolio

English portfolio for social posts, carousels and YouTube thumbnails, with After / Before comparisons.

- 3 posts, 1080 × 1350 PNG
- 1 carousel, 5 pages, 1080 × 1350 PNG
- 2 thumbnails, 1280 × 720 PNG
- Responsive static site with full-size artwork, slide navigation, Discord copy and Reddit contact.

Publish with GitHub Pages from the `main` branch, root folder. No build command or external dependencies are needed.

The Before panels show official source images, not earlier client designs. Final artwork was produced with AI assistance and is a creative interpretation; it is not scientific imagery.
